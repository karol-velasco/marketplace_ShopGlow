# ShopGlow – Marketplace 2.0

## Descripción del proyecto

ShopGlow es una aplicación móvil de comercio electrónico desarrollada con React Native y Expo. Su propósito es ofrecer un espacio donde los usuarios puedan encontrar diferentes productos de moda, belleza, papelería y manualidades en una misma tienda virtual.

La aplicación busca facilitar la experiencia de compra mediante herramientas que permiten consultar productos, comparar opciones, gestionar pedidos y realizar un seguimiento de las compras.

**Eslogan:** Un mundo de opciones para ti.

## Objetivo

Ampliar las funcionalidades de una tienda virtual mediante la implementación de nuevas opciones de compra, organización de pedidos y atención al usuario, mejorando la experiencia dentro de la aplicación.

## Tecnologías utilizadas

- React Native: desarrollo de la interfaz móvil.
- Expo: entorno de desarrollo y ejecución de la aplicación.
- JavaScript: lenguaje de programación.
- AsyncStorage: almacenamiento local de información.
- React Hooks: manejo de estados y actualización de la información.
- MaterialCommunityIcons: utilización de iconos en la interfaz.

## Funcionalidades principales

La aplicación cuenta con las siguientes funcionalidades:

- Consulta de productos por categorías.
- Búsqueda y filtros combinados.
- Selección de variantes de productos.
- Comparación de productos.
- Preguntas sobre los productos.
- Registro y administración de direcciones.
- Cálculo del costo de envío según el municipio y el tipo de entrega.
- Carrito de compras y proceso de compra simulado.
- Historial y seguimiento de pedidos.
- Cancelación de pedidos según su estado.
- Centro de notificaciones.
- Avisos de reposición de productos.
- Recomendaciones de productos relacionados.
- Centro de ayuda y solicitudes de soporte.

## Instalación y ejecución

Para ejecutar el proyecto en un computador, sigue estos pasos:

1. Clonar el repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

2. Ingresar a la carpeta del proyecto:

   ```bash
   cd NOMBRE_DE_LA_CARPETA
   ```

3. Instalar las dependencias:

   ```bash
   npm install
   ```

4. Iniciar el proyecto:

   ```bash
   npx expo start
   ```

5. Escanear el código QR con Expo Go desde un dispositivo móvil o utilizar alguna de las opciones disponibles para ejecutar la aplicación.

## Ejecución del proyecto

La aplicación permite realizar compras de manera simulada. Algunas acciones, como el avance de las entregas y la reposición de productos, se realizan mediante controles dentro de la aplicación y no representan servicios externos reales.
